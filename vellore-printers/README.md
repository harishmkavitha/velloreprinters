# Vellore Printers — static website

A self-contained multi-page marketing site (45 pages) for a print business.
Plain HTML/CSS/JS, no build step required to host. Deploys to GitHub Pages.

## Regenerating pages (optional)
All HTML is generated by the Python scripts in `tools/`.
    python3 tools/build.py
Edit copy/services in `tools/services_data.py` and templates in `tools/parts.py`,
then re-run. If you only hand-edit the HTML, you don't need Python at all.

## Adding real photos
Every image is a real photo slot backed by a geometric SVG fallback.
Open **IMAGES.md** for the full list of filenames and sizes. Drop a JPG with the
listed name into the matching folder under `assets/img/` and it appears
automatically — no rebuild, and no broken-image boxes before you do.

## Deploy to GitHub Pages
1. Create a repo named `vellore-printers` (public).
2. Upload every file/folder here (keep `.nojekyll` at the root — it's required).
3. Repo → Settings → Pages → Source: "Deploy from a branch" →
   Branch `main`, folder `/ (root)` → Save.
4. Wait ~1–2 minutes. Your site is at
   https://YOUR-USERNAME.github.io/vellore-printers/
5. (Optional) Custom domain: add it under Settings → Pages, create the DNS
   records your registrar shows, and add a `CNAME` file with the domain.
